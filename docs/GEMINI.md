# Gemini: необязательный бесплатный анализ

Бот работает без Gemini. Включение предназначено только для личного бота взрослого владельца в поддерживаемой стране; это не разрешение встраивать Gemini в сервис для школьников. [Условия API](https://ai.google.dev/gemini-api/terms) требуют 18+ и запрещают API Clients, направленные на лиц младше 18 лет или вероятно доступные им. Для пользователей ЕЭЗ, Швейцарии и Великобритании условия требуют Paid Services: в этом бесплатном проекте Gemini для них не включать. Россия отсутствует в [списке доступных регионов](https://ai.google.dev/gemini-api/docs/available-regions).

Free Tier использует входы и ответы для улучшения продуктов, возможен просмотр людьми. Не передавать персональные, конфиденциальные или чувствительные сведения. В модель передаются только публичные поля мероприятия и официальный регламент; профиль владельца, Telegram и секреты не передаются. См. [условия обработки данных](https://ai.google.dev/gemini-api/terms#unpaid-services).

Включение требует одновременно `GEMINI_ENABLED=1`, `GEMINI_ADULT_CONFIRMED=1`, `GEMINI_AVAILABLE_REGION_CONFIRMED=1`, `GEMINI_FREE_TIER_CONFIRMED=1`, `GEMINI_API_KEY` и `GEMINI_MODEL`. Владелец подтверждает, что модель доступна бесплатно, проект без активного billing и регион допускает Unpaid Services. Не подключать billing: локальный счётчик сам по себе не гарантирует отсутствие оплаты в платном проекте. Модель задаётся явно, поскольку доступность меняется: [тарифы](https://ai.google.dev/gemini-api/docs/pricing).

`GEMINI_DAILY_LIMIT` задаёт локальное число попыток в сутки UTC (по умолчанию 10, максимум 100); `GEMINI_QUOTA_PATH` — SQLite-файл (по умолчанию `.state/gemini-quota.sqlite3`). Каждая попытка резервируется до сети, включая неудачную. Хранилище нужно сохранять между запусками. Ошибка хранилища, лимит, HTTP 429, тайм-аут и невалидный ответ включают локальный анализ; платного fallback нет. Квоты Google действуют на проект, не на ключ, могут меняться; [активные лимиты](https://ai.google.dev/gemini-api/docs/rate-limits) смотреть в AI Studio.

Регламент считается недоверенными данными. Модель не имеет инструментов, не выполняет команды и не выбирает сетевые адреса. Подтверждение разрешения/запрета ИИ требует дословной цитаты из официального регламента и явной формулировки. Отсутствие запрета не означает разрешение. Результат — предварительный обзор: ссылки на первоисточник сохраняются, неоднозначные правила остаются неизвестными. Ключ хранится только в окружении, не в клиентском коде или git: [защита ключей](https://ai.google.dev/gemini-api/docs/api-key#security).

## Локальный профиль

Локальная оценка учитывает Web CTF, AI/LLM security, red teaming, prompt injection, AI agents, программирование, призы, бесплатность, онлайн-формат и источник. Баллы складываются один раз за каждую категорию и ограничиваются 0–100. Это приоритет просмотра, а не подтверждение пригодности или разрешения ИИ. По умолчанию: база 10; CTF +30; AI security +35; agents +25; coding +10; prizes +15; online +10; free +10; CTFNews/CTFtime +10, AIcrowd/Devpost +5. Источник сопоставляется без учёта регистра по точному имени. Факты бесплатности и онлайн-участия не выводятся только из названия источника.

`RADAR_PROFILE_PATH` указывает на локальный JSON владельца, полностью заменяющий профиль:

```json
{"base":10,"topics":{"security":{"weight":60,"keywords":["web ctf","prompt injection"]},"online":{"weight":10,"keywords":["online","онлайн"]}},"sources":{"CTFNews":10}}
```

Неверный или недоступный файл включает профиль по умолчанию. Слова ищутся без учёта регистра в title/description/prize/format; пользователь может задать отрицательные веса. Путь никогда не берётся из загруженного события. События без непустого description или rules_text не расходуют Gemini-квоту.

Политика ИИ признаётся только по полному совпадению отдельной явной декларации (например, `Use of AI is allowed` или `Использование ИИ запрещено`). Условия, исключения и соседние оговорки оставляют результат неизвестным, как и любые другие неоднозначные предложения об ИИ. Этот намеренно узкий распознаватель пропускает часть реальных разрешений; открытие официального регламента остаётся обязательным перед участием.

## Проверка живого доступа

24 ноября 2026 года повторно проверены официальные pricing, available-regions, terms и rate-limits: Free Tier существует, но доступен для ограниченного набора моделей; фактическая квота и разрешённые модели определяются проектом в AI Studio. Наличие Free Tier на странице не подтверждает доступ конкретного аккаунта. Условия также ограничивают использование профессиональными/деловыми целями разработчиков; личное потребительское использование отдельно не разрешено этими условиями. Владелец должен проверить соответствие своего сценария до включения.

В текущей среде `GEMINI_API_KEY` и `GEMINI_MODEL` отсутствуют, четыре явных подтверждения включения отсутствуют. Живой запрос намеренно не выполнен. Проверены только официальная документация и offline-тесты HTTP-обмена; это не успешная end-to-end проверка Gemini. Ключи в диагностике не печатались.

Для последующей проверки после выполнения всех условий использовать один искусственный публичный пример без персональных данных с дневным лимитом 1 и постоянным файлом квоты. Не передавать реальные документы до проверки допустимости их содержимого. Успех `analyze()` не доказывает успех API, поскольку контракт предусматривает тихий локальный fallback; при проверке контролировать факт успешного HTTP-ответа отдельно, не выводя заголовки, ключ или исходное содержимое. Нельзя обходить региональные ограничения или подключать оплачиваемый проект ради теста бесплатного сценария.
