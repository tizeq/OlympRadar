## Ограничения

Проверенный список не покрывает все страны, сезоны и категории. Сайты могут изменить разметку или объявленные сроки. Олимпиада.ру иногда показывает расходящиеся сроки будущего этапа в кратком анонсе и шкале; бот использует явно размеченную шкалу, прикладывая ссылку на источник.

До четырёх карточек площадки за запуск могут получить дополнительный запрос страницы и отдельный запрос официального регламента. Условия участия по ссылке Rules извлекаются на том же хосте для официальных платформ. Инструкции в тексте не исполняются. Для ручного уточнения SOURCE_OVERRIDES_FILE задаёт путь к локальному JSON с ключами по точному URL события. Поддерживаются rules_url, registration_url, start, end, registration_start, registration_end и deadline. При отсутствии подтверждённых характеристик значение остаётся неизвестным.
