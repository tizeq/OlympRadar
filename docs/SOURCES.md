# Источники OlympRadar

Проверено по официальным страницам 24 ноября 2026 года. Доступность страницы в web-поиске не равна проверке сетевого доступа из среды запуска. Здесь DNS недоступен; адаптеры проверяются локальными ответами. Сборщик не обходит авторизацию и защиту сайтов.

HTML-адаптеры возвращают кандидатов, а не подтверждённую возможность участия. Даты, призы, ограничения и разрешение AI неизвестны, пока их нет в структурированном ответе или официальном регламенте. Текст анонса никогда не записывается в `rules_text`. Отказ/пустая разметка источника фиксируется в журнале; остальные источники продолжают работу. Перед эксплуатацией проверить правила сайтов и актуальную разметку из сети развёртывания; фикстуры проверяют парсер, но не доступность сайта.

## Обогащение и официальные регламенты

До четырёх страниц событий каждой площадки за один запуск получают дополнительную загрузку, чтобы один каталог не исчерпал общий бюджет. Явные сообщения о завершении, отменённые JSON-LD Event и прошедшие `endDate` исключаются. Это не гарантирует актуальность карточек без дат. Неоднозначные страницы остаются кандидатами с неизвестными сроками. Codeforces берётся только с фазой BEFORE и не требует дополнительной загрузки, если нет override. Для CTFtime допустимы только ссылки вида `https://ctftime.org/event/123/`.

На Devpost, AIcrowd и Codeforces ссылки с явным названием Rules/Official Rules/Регламент и Register/Регистрация принимаются только с того же хоста. Регламент загружается отдельно и становится `rules_text`; JavaScript и CSS удаляются. Ссылки из медиа автоматически не считаются официальными. Никакие инструкции из текста не исполняются. Ошибка регламента оставляет событие с `rules_url` и неизвестной AI-политикой.

Для событий с нестабильной разметкой оператор может задать `SOURCE_OVERRIDES_FILE` — путь к локальному JSON, ключи которого точно совпадают с URL обнаруженного события. Это явное подтверждение оператором официального назначения ссылок, включая внешний домен организатора:

```json
{
  "https://ctfnews.ru/news/example-event/": {
    "rules_url": "https://organizer.example.org/competition/regulations",
    "registration_url": "https://organizer.example.org/competition/register",
    "deadline": "2027-02-01T18:00:00+03:00"
  }
}
```

Пример демонстрирует формат, а не существующее событие. Допустимы только публичные HTTPS URL без учётных данных и нестандартных портов. IP локальных сетей и редиректы отвергаются; используйте конечный канонический адрес. Файл — доверенная локальная конфигурация, его нельзя формировать из текста анонсов. `deadline` означает проверенный срок регистрации/подачи, `start` и `endDate` его не заменяют. Просроченный override-дедлайн исключает событие. Проверка IP при URL-валидации не заменяет сетевые ограничения от DNS rebinding в среде развёртывания.
