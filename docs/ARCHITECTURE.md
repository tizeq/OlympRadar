# OlympRadar в Telegram
GitHub Actions обновляет публичную SQLite в catalog-data раз в сутки. Сбор, анализ, кэш и история версий изолированы от webhook. D1 хранит индекс FTS5 и персональные фильтры, подписки и историю сводок. Кнопки и текстовые запросы обрабатывает Worker через Telegram Bot API. Секреты передаются только серверу.

Перед отправкой непустой сводки сервер резервирует день пользователя в его часовом поясе. Неопределённый ответ Telegram может привести к пропуску этой сводки. Старая настройка срочных сообщений игнорируется. Повторный сбор сохраняет идентификаторы событий и ранее полученные записи при отказе источника.
