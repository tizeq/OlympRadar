# Архитектура
Один короткоживущий процесс опрашивает публичные каталоги, сопоставляет адреса и нормализованное название с датой, фильтрует по профилю и отправляет в один настроенный чат. Источники, оценка и доставка разделены по контрактам. Модель получает текст как данные, без инструментов. Подтверждение политики ИИ требует цитаты из регламента.

Публичный репозиторий и стандартный Linux runner обеспечивают бесплатное расписание. Журнал содержит хеши ключей. Резервирование перед отправкой предотвращает повтор после неопределённого ответа Telegram ценой возможного пропуска. Секреты предоставляет окружение.
