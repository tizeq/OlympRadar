# Последовательность
1. Проверить каталоги, условия GitHub и Gemini, зафиксировать интерфейсы.
2. Параллельно реализовать источники, оценку и доставку с тестами в непересекающихся файлах.
3. Интегрировать CLI, проверить повторный запуск, тайм-ауты и отказ модели.
4. Запустить проверки, документировать эксплуатацию и пределы покрытия.
