# Контракты бота
Telegram присылает message и callback_query на POST /telegram с секретом webhook. Сервер принимает персональные команды из личного чата, привязывает настройки к подтверждённому Telegram user ID и резервирует update_id перед ответом. handleUpdate(update, env) строит текстовые сообщения и inline-кнопки. Ссылки на внешние сайты ведут только к источнику и регистрации.

Сборщик раз в сутки обновляет SQLite и экспортирует catalog.json и catalog-aliases.json. Worker импортирует публичные карточки в D1 (SQLite); пользовательские запросы, фильтры и сводки используют локальные таблицы. category описывает тип, tags — темы. Даты start и end относятся к проведению, registration_start и registration_end — к регистрации, deadline — отдельный подтверждённый срок. Неизвестные значения остаются NULL. Сводка получает callback_data=catalog.
