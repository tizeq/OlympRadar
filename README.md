# OlympRadar
Откройте [@itolympics_bot](https://t.me/itolympics_bot) и отправьте **/start**. Бот покажет поиск, олимпиады, CTF, хакатоны, гранты, фильтры и подписки. Результаты, карточки и настройки открываются сообщениями в этом же чате.

GitHub Actions ежедневно обновляет публичный каталог SQLite. Поиск читает SQLite в D1. За сбор и поиск отвечают бесплатные компоненты, анализ Gemini включается отдельно. Персональные подписки позволяют получать одну сводку с новыми подходящими событиями.
