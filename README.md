# OlympRadar

Личный Telegram-бот ищет соревнования по расписанию и присылает карточки с оценкой по интересам владельца. Один экземпляр обслуживает один чат. Python 3.11 или новее, зависимости входят в стандартную библиотеку.

## Первый запуск

Из каталога проекта выполните:

```bash
python3 -m unittest discover -s tests
python3 -m radar
```

Предпросмотр обращается к каталогам и печатает подходящие события. Для доставки создайте бота в BotFather, откройте чат с ним, настройте секреты и инициализируйте журнал по [инструкции развёртывания](docs/DEPLOY.md). Затем запустите OlympRadar через Actions → Run workflow. Расписание запрашивает запуск раз в два часа. Порог интереса задаёт MIN_SCORE от 0 до 100.

Сбор работает без ключа модели. Чтобы включить обработку публичных регламентов в Gemini, проверьте доступность бесплатной модели, возрастные и региональные условия. [Настройка Gemini и профиль](docs/GEMINI.md).

## Покрытие

Codeforces предоставляет даты будущих раундов. Для HTML-каталогов доступность карточек зависит от разметки площадки. Отсутствующие дедлайны, призы и условия участия могут остаться неизвестными. Точная дата старта и нормализованное название либо общий адрес связывают публикации разных площадок. Переименованные события без общего адреса или даты могут дать отдельные карточки. [Каталоги и ограничения](docs/SOURCES.md).

Состояние отправки хранится в отдельной ветке. После записи попытки сбой Telegram может привести к пропуску сообщения. Эта схема защищает от повторной отправки при перезапуске. Секреты передаются через переменные окружения или GitHub Actions Secrets.
