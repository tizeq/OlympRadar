# OlympRadar

Telegram Mini App для поиска олимпиад, CTF, AI-соревнований и хакатонов. Каталог обновляется раз в сутки. Поиск, фильтры, календарь, рекомендации и избранное работают с базой данных. Найденные карточки доступны в приложении; подписка позволяет получать персональную сводку.

## Компоненты

- Python собирает события существующими адаптерами, сопоставляет дубликаты и публикует каталог SQLite и JSON. Gemini Free Tier опционально уточняет метаданные при изменении события.
- Worker обслуживает Mini App, проверяет подпись Telegram, выполняет поиск FTS5 в D1 и обрабатывает команды бота.
- React и TypeScript отображают карточки, настройки и сохранённые запросы. Ключи Telegram и Gemini доступны только на сервере.

## Запуск

```bash
python -m unittest discover -s tests
python -m collector --db .state/dev.sqlite --export .state/catalog.json
```

Полная инструкция включает настройку D1, применение миграций, сборку UI, тестирование и привязку кнопки к Telegram.
